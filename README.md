# nighteditor

Claude 아티팩트 같은 HTML 문서를 브라우저에서 클릭해 고치고,
**원본을 최소 diff 로 되돌려주는** 로컬 편집 도구.

한 파일이어도 되고, 스타일과 그림을 옆에 둔 폴더나 zip 이어도 된다.

한 문단을 고치면 `diff` 도 그 한 줄만 나온다. 들여쓰기·속성 순서·엔티티 표기는
건드리지 않은 한 바이트 단위로 보존된다.

**https://code0xff.github.io/nighteditor/**

## 쓰는 법

브라우저에서 위 주소를 열면 바로 쓸 수 있다. 로컬에서 돌리려면:

```bash
pnpm install
pnpm dev
```

1. HTML 이나 zip 을 창에 끌어다 놓거나 **파일 열기** 를 누른다 (폴더째 열려면 **폴더 열기**)
2. 글자를 클릭해 고친다 — `Enter` 로 확정하고 닫고, `Shift+Enter` 로 줄을 바꾸고, `Esc` 로 취소한다
3. **저장** (`Ctrl+S` / `⌘S` — 프리뷰 안에서 눌러도 된다)

원본을 건드리지 않고 결과물만 파일로 받으려면 **사본 내려받기**(`Ctrl+Shift+S`).
`Ctrl+Z` 는 편집 중이면 브라우저 undo, 편집 밖이면 마지막 변경 되돌리기다.

`파일 열기`·`폴더 열기` 로 연 것만 덮어쓸 수 있다. 끌어다 놓은 것은 핸들이 없어 내려받기로 저장된다.
덮어쓰기는 File System Access API 를 쓰므로 **Chromium 계열** 에서만 동작한다.

**고친 결과물은 어디에 있나** — 저장하면 어느 쪽이었는지 문장으로 뜬다.
`… 파일에 저장했어요` 면 원본 파일이 그 자리에서 바뀐 것이라 따로 내려받을 것이 없고,
`… 파일로 내려받았어요` 면 같은 이름으로 다운로드 폴더에 떨어진다.
누르기 전에 툴바 오른쪽 안내(`끌어다 놓은 파일은 덮어쓸 수 없어요`)로도 구분된다.

UI 언어는 툴바에서 **한국어 / English** 를 고른다.

### 설치해서 쓰기 (PWA)

주소창의 설치 버튼으로 앱처럼 설치할 수 있다. 설치하면:

- **오프라인에서 동작한다.** 백엔드가 없어 앱 전체가 미리 캐시된다
- **OS 에서 HTML 을 바로 열 수 있다.** 파일을 우클릭해 nighteditor 로 열면
  파일 선택 대화상자 없이 바로 편집되고, 원본 덮어쓰기도 그대로 된다

자세한 사용법·문제 해결은 [docs/guide.md](docs/guide.md).

## 옆에 파일을 둔 문서

`deck.css` 나 `logo.png` 를 따로 두고 참조하는 문서는 파일 하나만 열면 그 자원이 빠진 채
보인다. 파일 하나를 여는 것으로는 브라우저가 옆 파일을 볼 권한을 주지 않기 때문이다.

**폴더 열기** 로 열거나, 화면에 뜨는 **폴더 연결하기** 를 누르면 원래 모습대로 보인다.
zip 을 통째로 놓아도 된다 — 압축은 브라우저가 풀고, 파일은 이 기기를 떠나지 않는다.

자원을 못 붙여도 **고치고 저장하는 데는 지장이 없다.** 화면이 어떻게 보이든 결과물의
diff 는 똑같이 정확하다 — 이 도구는 화면이 아니라 원본 문자열을 고치기 때문이다.

## 무엇을 고칠 수 있나

문단·제목·표 셀·목록 항목 등 **텍스트를 담은 블록**이 대상이다.
문서 제목(`<title>`)은 화면에 안 보이므로 상단의 별도 필드로 고친다.

아래는 **잠긴다.** 왜 잠겼는지는 오른쪽 패널에 나온다.

| 사유 | 뜻 |
|---|---|
| 코드 영역 | `script`·`style`·`textarea` 안 — 텍스트가 아니라 코드다 |
| 스크립트가 만든 글자 | 렌더 결과가 소스와 달라 되짚을 곳이 없다 |
| 원본에는 비어 있는 자리 | 소스에는 빈 요소이고 내용은 스크립트가 채운다 |
| 코드 블록 | 수동 하이라이팅된 코드/JSON — 고치면 구조가 깨진다 |
| 고칠 범위가 불분명 | 닫는 태그가 생략되어 위치를 확정할 수 없다 |

추측으로 고치느니 못 고친다고 말하는 쪽을 택했다.

## 왜 이렇게 만들었나

편집 결과는 **원본 문자열에 패치를 적용한 것**이지 DOM 을 재직렬화한 것이 아니다.
브라우저가 DOM 을 다시 문자열로 뽑으면 정규화 규칙에 따라 문서 전체가 다시 쓰이고,
한 문단 고쳤는데 diff 가 파일 전체로 뜬다. 수정본을 Claude 에 다시 넣을 때도 손해다.

설계 배경과 근거는 [docs/architecture.md](docs/architecture.md) 의 ADR 을 참고.

## 개발

```bash
pnpm verify   # typecheck + lint + format + test + build
```

회귀 테스트는 `src/__fixtures__/artifact.html` 을 대상으로 돈다.
새 규칙을 만들 땐 근거가 된 구조를 픽스처에 먼저 넣고 테스트를 쓴다.

`dev` 가 유일한 브랜치다. 작업 규칙은 [AGENTS.md](AGENTS.md) 에서 시작한다.

```bash
git config core.hooksPath .githooks   # 클론 후 1회 — push 전 verify 강제
```
