# Spec

## 1. 범위

### 하는 것
- 단일 HTML 파일을 열어 블록 단위로 텍스트를 클릭 편집
- 편집 결과를 원본 최소 diff로 저장
- 편집 불가 영역을 시각적으로 구분해 표시
- 블록 단위 되돌리기, 전체 초기화

### 하지 않는 것 (범위 밖)
- 스타일·레이아웃 편집 (CSS, 색상, 간격)
- 요소 추가·삭제·이동
- 이미지 교체
- 다중 파일 / zip 프로젝트
- 협업, 계정, 클라우드 저장
- HTML을 처음부터 만드는 기능

## 2. 편집 블록 판정

### 인라인 태그 집합
```
b, strong, span, br, small, i, em, a, code, u, sup, sub
```

### 판정 알고리즘
루트부터 순회하며, 각 요소에 대해:

1. 자식 중 **인라인이 아닌 요소**가 하나라도 있으면 → 블록이 아님, 자식으로 재귀
2. 그렇지 않고 공백이 아닌 텍스트를 (직접 또는 인라인 자손 안에) 가지면 → **편집 블록**
3. 둘 다 아니면 → 무시

즉 "텍스트를 담은 가장 바깥 요소이면서, 그 안이 인라인 마크업뿐인 것"이 블록이다.

레퍼런스 파일 결과: **867개** (`div` 256, `td` 241, `p` 103, `li` 72, `span` 70, `h2` 43, `th` 42, `h3` 36, `button` 2, `title` 1, `h1` 1)

### 2.1 `<title>` 특례

`<title>`은 위 규칙으로 블록이 되지만 **프리뷰에 렌더되지 않으므로 클릭이 닿지 않는다.**
에디터 상단의 **별도 입력 필드**로 편집한다. 패치 경로는 다른 블록과 완전히 동일하다.

제약 — `<title>`은 RCDATA라 내부에 태그를 넣을 수 없다.
**평문 전용**으로 편집하고, `&`·`<`는 엔티티로 인코딩해 기록한다.

### 2.2 합성 노드 주의

parse5는 스펙에 따라 **소스에 없는 노드를 트리에 삽입한다.**
레퍼런스 파일에서는 테이블 13개에 `<tbody>`가 자동 삽입되며, 이 노드들의
`sourceCodeLocation`은 `null`이다. 순회 시 반드시 null을 가드한다 (`rules.md` INV-7).

### 블록이 보관하는 정보
```ts
type Block = {
  id: number
  tag: string
  innerStart: number   // 원본 문자열 offset (여는 태그 '>' 다음)
  innerEnd: number     // 닫는 태그 '<' 앞
  sourceInner: string  // 원본 innerHTML 원형
  sourceText: string   // 태그 제거한 순수 텍스트 (대조 검사용)
  locked: LockReason | null
}
```

## 3. 잠금 규칙

아래에 해당하면 편집 불가로 잠그고, 이유를 UI에 노출한다 (대원칙 3).

| 잠금 사유 | 판정 시점 | 설명 |
|---|---|---|
| `RAW_TEXT` | 파싱 | `script`, `style`, `textarea` 내부 |
| `SCRIPT_GENERATED` | 렌더 후 | 라이브 `textContent` ≠ `sourceText` (ADR-005) |
| `EMPTY_IN_SOURCE` | 파싱 | 소스에서 비어 있음 — 스크립트가 채우는 자리 |
| `CODE_BLOCK` | 파싱 | 수동 하이라이팅된 코드/JSON 영역 (기본 잠금, 설정으로 해제 가능) |
| `AMBIGUOUS` | 파싱 | offset 매핑이 유일하게 결정되지 않음 |

`EMPTY_IN_SOURCE`는 §2 판정 규칙(텍스트 없으면 블록 아님)에 의해 자동 제외된다.
레퍼런스 파일의 `<span class="pg">` 40개가 여기 해당한다.

### 엔티티 — 대조 검사의 함정

`SCRIPT_GENERATED` 판정은 **디코딩된 텍스트끼리** 비교해야 한다. 원시 소스 슬라이스로 비교하면
엔티티를 포함한 멀쩡한 블록이 전부 오탐으로 잠긴다.

```
소스 슬라이스 : "Appendix B · Protocols &amp; Standards"
라이브 텍스트 : "Appendix B · Protocols & Standards"      ← 다르게 보이지만 같은 내용
```

레퍼런스 파일에는 엔티티가 1개뿐이라 눈에 띄지 않지만, 코드 예시가 많은 아티팩트에서는
`&lt;` / `&gt;` / `&amp;` 가 대량으로 등장한다. `rules.md` INV-8 참조.

### 코드 블록 기본 잠금 근거
레퍼런스 파일의 JSON 예시는 `<pre>`가 아니라 `<span class="h">` / `<span class="v">`로
수동 하이라이팅되어 있다. 중복 문자열 상위를 이 조각들이 차지한다 (`":"` 67회, `","` 61회).
자유 편집을 허용하면 하이라이팅 구조가 깨지므로 기본은 잠금이다.

## 4. 사용자 플로우

```
1. 파일 열기        드래그&드롭 또는 파일 선택 (File System Access API 핸들 확보)
2. 렌더             마커 주입본을 iframe에 렌더, 아티팩트 스크립트 정상 실행
3. 대조             소스-라이브 검사 → 잠금 확정 → 편집 가능 블록에 호버 하이라이트
4. 편집             클릭 → contenteditable 활성 → 수정 → blur/Esc 로 확정
5. 확인             변경된 블록 목록과 diff 미리보기
6. 저장             Ctrl+S → 원본 파일 덮어쓰기 (폴백: 다운로드)
```

### 편집 상호작용
- 클릭: 해당 블록만 `contenteditable=true`, 나머지는 false
- `Esc`: 편집 취소, 원래 내용 복원
- `Ctrl+Z`: 자체 실행취소 스택 (네이티브 undo 비활성)
- 붙여넣기: 서식 제거, 평문만 삽입
- 아티팩트 자체 키 핸들러(방향키 슬라이드 이동 등)는 편집 중 차단

### 아티팩트 이벤트와의 충돌

아티팩트는 자체 전역 핸들러를 갖는다. 레퍼런스 파일은 `document` 클릭으로 슬라이드를 넘긴다.

```js
document.addEventListener('click', function(e){
  if(e.target.closest('table,ul.list,.tl,.defs,.code')) return;
  show(e.clientX < window.innerWidth*0.18 ? i-1 : i+1);
});
```

즉 `<p>`나 `<h2>`를 편집하려고 클릭하면 **편집이 켜지는 동시에 슬라이드가 넘어간다.**

프리뷰 에이전트는 `click` / `keydown` / `touchend` 를 **캡처 단계**(`{capture:true}`)에서 가로채
편집 중이면 `stopPropagation()` 으로 아티팩트 핸들러에 도달하지 않게 한다.
아티팩트 스크립트보다 먼저 등록된다는 보장이 없으므로 버블 단계로는 막을 수 없다.

### 한글 IME
`compositionstart` ~ `compositionend` 사이에는 값을 읽지 않는다.
조합 중 상태를 패치로 반영하면 자모가 깨진다. 확정 이벤트 이후에만 패치를 갱신한다.

## 5. 저장 동작

1. 패치 목록을 `innerStart` **내림차순**으로 정렬 (앞에서부터 자르면 뒤쪽 offset이 전부 밀림)
2. 원본 문자열에 순서대로 스플라이스
3. 결과를 파일 핸들에 write, 실패 시 다운로드 폴백

편집하지 않은 블록은 패치 목록에 없으므로 원본 바이트가 그대로 남는다.

## 6. 합격 기준

`agent_payments.html` 기준:

- [ ] 편집 블록 **867개**가 모두 인식된다 (`<title>` 포함)
- [ ] `.pg` 40개와 `#cnt`가 `SCRIPT_GENERATED` 또는 `EMPTY_IN_SOURCE`로 자동 잠긴다
- [ ] `wrapSheets()` 실행 후에도 모든 블록의 마커가 유효하다
- [ ] 블록 1개 수정 → `diff` 결과가 **해당 줄만**
- [ ] 아무것도 수정하지 않고 저장 → 원본과 **바이트 단위로 동일**
- [ ] 인라인 `<b>`가 있는 블록(295개) 편집 후에도 `<b>`가 보존된다
- [ ] 한글 입력 시 자모 깨짐 없음
- [ ] 저장본을 다시 열면 슬라이드 네비게이션이 정상 동작한다
- [ ] `<title>` 을 별도 필드로 수정 → diff 해당 줄만
- [ ] `<tbody>` 합성 노드 13개에서 순회가 죽지 않는다
- [ ] `&amp;` 포함 블록이 `SCRIPT_GENERATED` 로 오탐 잠금되지 않는다
- [ ] 편집 중 클릭·방향키가 슬라이드를 넘기지 않는다
